# AI A → AI B 인수인계 (공개 커밋 확정 전 초안 — 아직 B에게 전달하지 말 것)

## 1. 목표
서울 기온 정보판에 실제 일별 기록 CSV 다운로드 한 기능 추가. 시작 소스: https://github.com/rlatmdgus4141/aleph-real-board/tree/dc0cff94a66a6848b9794fd86e6f48f9ae49a17f
CSV 열: 날짜·기온·단위·출처·출처 URL·출처 시각·조회 시각.
공통 한도: 각 세션 60분 / 사용자 요청 10회. 내부 도구 호출은 사용자 요청 수에 미포함.

## 2. 현재 상태
A는 index.html에 순수 함수 buildRealRecordsCSV(readings)를 추가했다. UTF-8 BOM, 날짜 오름차순, CSV 따옴표 이스케이프, 원본 비변경을 구현했다.
CSV 버튼과 이벤트 처리는 아직 없다. A는 사전 계획한 핵심 함수 구현 단계에서 인계한다.
A 종료 공개 소스 버전: 사용자가 파일을 GitHub에 커밋한 뒤 실제 SHA로 확정할 예정. 이 문서는 확정본이 아니다.
기존 기록 2026-09-30 24°C / 2026-10-01 17.3°C 및 기존 T04 기능은 수정하지 않았다.

## 3. 실행 명령
필요: Node.js 24.x, Git. npm 설치·외부 패키지·API 키 불필요.
확정된 저장소를 새 폴더에 clone하고 확정된 A 종료 SHA를 checkout한 뒤 저장소 루트에서:
```sh
node --version
node t05/test-csv.cjs
```
실패 시 종료 코드는 1이다. 결과 JSON은 표준 출력이다. 보존할 때 `node t05/test-csv.cjs > t05/b-results-round-1.json`을 사용하고 종료 코드도 확인한다.
화면은 index.html을 브라우저에서 연다. 필요하면 Python 3의 `python -m http.server 8000`으로 연다.
검사는 DOM 모형에서 실제 페이지 스크립트와 버튼 핸들러를 실행한다. 실제 브라우저 파일 다운로드·레이아웃 검증을 대신하지 않는다.

## 4. 통과 검사
A의 고정 검사 결과: 0/10 PASS, 10/10 FAIL. 실행 2회, 오류 회차 2회. 두 번째는 새 폴더에서 같은 명령으로 재현했다.
모든 실패 원인은 CSV 다운로드 버튼(export-csv) 미구현이다. 결과: t05/a-results-round-1.json 및 t05/a-results-round-2-fresh-folder.json.
고정 실행 검사: t05/test-csv.cjs
SHA-256: f6e343e5303ce99a6e6fffe3e311ba4dda0670b631a4e56b084fdc740450f0aa
별도 브라우저 검사 미실행. 미실행을 PASS로 표시하지 않는다.

## 5. 남은 문제
CSV 사용자 조작 경로 미구현. CSV-01~10 전체 통과 필요.
플랫폼에 등록한 서비스·모델명과 실제 시작·종료 시각은 사용자의 과정 기록으로 확정해야 한다.
A/B는 순차 작업이므로 통과 수만으로 일반적인 모델 성능 우열을 주장할 수 없다.

## 6. 다음 행동
보존 기록·공개본 영역에 id="export-csv" 버튼을 만들고 onclick을 연결한다.
입력은 live.daily_readings의 row.reading만 사용한다. replay는 사용하지 않는다.
0건이면 showToast('내려받을 실제 기록이 없습니다') 후 종료한다.
그 외에는 buildRealRecordsCSV로 직렬화하고 기존 download 함수로 .csv 파일을 내려받는다.
고정 검사 10개를 실행하고 실패 회차도 전부 보존한다. 새 폴더에서 재현하고 실제 브라우저에서도 다운로드·빈 기록·한글을 확인한다.
기록 포함 공개본 HTML 다운로드에도 CSV 기능이 남는지 확인한다.
B 종료 시 실제 시간/요청 수/오류 회차/통과 수/시작·종료 commit을 기록한다.
공개 비교 보고서는 두 도구 이름을 가린 측정표를 제공한다. B 결과·사용자 판단을 지어내지 않는다.

## 7. 건드리지 말 것
고정 검사 10개 삭제·완화·기대값 변경 금지. 테스트 파일 해시 유지.
기존 실제 조회, JSON/HTML 다운로드, 공식 합성 검사, official-files 및 public-evidence 변경 금지.
실제 API를 재조회해 보존된 제출 기록을 바꾸지 않는다. 비밀값·개인정보·대화 전문을 넣지 않는다.
인수인계 문서 누락 시 원본 보존 후 수정 전후를 남긴다. A 인계 내용과 B가 받은 내용은 바이트 단위로 같아야 한다.
