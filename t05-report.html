## 공통 최초 요청
과제 4의 서울 기온 정보판에 ‘실제 일별 기록 CSV 내려받기’ 기능을 추가해주세요. 제공된 저장소와 인수인계 문서가 있다면 해당 문서를 기준으로 현재 상태부터 이어서 작업하세요.

CSV 열은 날짜·기온·단위·출처·출처 URL·출처 시각·조회 시각의 7개로 고정합니다. 고정 검사 CSV-01~CSV-10을 삭제·완화하거나 기대값을 변경하지 마세요. 기존 실제 조회, JSON 다운로드, 공개본 HTML 다운로드, 합성 검사 기능을 유지하고 합성 기록은 CSV에서 제외하세요.

공통 상한은 세션별 60분, 사용자 작업 요청 10회입니다. 이번 실행에서는 시작 기록부터 종료·인계 기록까지의 경과시간을 중단 시간 포함으로 측정합니다. 최초 작업 요청과 후속 요청을 각각 1회로 세고 내부 도구 호출은 제외합니다. 오류 수는 고정 검사 중 하나라도 FAIL이 나온 실행 회차 수로 계산합니다.

AI A는 CSV 생성 함수까지 구현한 뒤 사용자 다운로드 버튼 연결을 남겨 인계하고, AI B는 이를 이어받아 기능을 완성합니다. 각 단계의 실제 검사 결과와 소스 버전을 보존하세요. 인수인계 문서는 목표·현재 상태·실행 명령·통과 검사·남은 문제·다음 행동·건드리지 말 것의 7항목으로 작성하세요.

A 안내의 Node 24.x와 달리 B는 22.22.0을 사용했으며 고정 검사와 새 폴더 실행이 통과했습니다. B 종료 문서의 로컬 커밋 실행 예시는 공개 저장소에서 받을 수 없으므로 아래 공개 커밋 명령을 최종 재현 안내로 제공합니다. 원문은 수정하지 않고 이 보완 내용을 분리해 남겼습니다.
